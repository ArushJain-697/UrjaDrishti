# UrjaDrishti — KREDL / KSPDCL Renewable Forecasting

UrjaDrishti is an AI-enabled forecasting system for Karnataka renewable generation.
It provides:
- Plant and cluster forecasts (P10 / P50 / P90)
- Explainability alerts
- Evaluation baselines and stress testing
- Dashboard views for operations (Plant, Cluster, Evaluation, Logbook, War Room)

---

## Prerequisites

- Python 3.10+ (3.11/3.12 recommended)
- Node.js LTS (18+ recommended) and npm
- Git

---

## One-command startup

From repository root:

### macOS / Linux
```bash
bash start.sh
```

### Windows (CMD)
```bat
start.bat
```

The startup script automatically:
1. Creates/uses backend virtual environment
2. Installs backend dependencies
3. Runs Person 2 + Person 3 forecasting pipeline
4. Runs Person 4 evaluation scripts
5. Installs frontend dependencies and starts Vite

---

## What success looks like in terminal

You should see these checkpoints:
- `Person 2 + Person 3 pipeline completed.`
- `Person 4 evaluation completed.`
- `SYSTEM READY`
- `Dashboard: http://localhost:5173`

On frontend startup you should also see:
- `VITE ... ready`
- `Local: http://localhost:5173/`

If any step fails, the startup script now stops immediately and prints the failing step.

## Frontend verification checklist

After startup, open `http://localhost:5173` and verify:
- Plant View: forecast chart, confidence, explainability alerts
- Cluster View: reconciliation toggle and stacked bars
- Evaluation: metrics table, forecast ledger, model health
- Logbook: add/search/filter entries
- War Room: fullscreen live monitor
- Language toggle: English/Kannada UI switching

## Manual run (if needed)

### Backend only
```bash
cd backend
python -m venv venv
source venv/bin/activate    # Windows: venv\Scripts\activate
python -m pip install -r requirements.txt
PYTHONPATH=. python -m src.ml.forecasting.main
```

### Frontend only
```bash
cd frontend
npm install
npm run dev
```
